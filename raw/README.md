# raw/ —— 冷层 / 原始事件全量

这里放你**自己的**原始事件。本目录内容全部被 gitignore,**永不进公开仓库**。

约定(就一条):每次"坐下来干一段活"= 一个目录,目录名 `YYYY-MM-DD-HHMMSS-<label>`。
里面怎么乱都行——transcript、log、prompt、截图、随手记。别在写入时判断"这算不算一个事件",那是读取时的事。

用 `./tools/add` 丢东西,别手动建。

记住根:**append-only · 原始 · 永不就地改。** 要脱敏?那是把它做成公开样例时(`./tools/scrub`)的事,产出副本,不动这里的原件。
